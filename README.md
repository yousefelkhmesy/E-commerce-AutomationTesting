E-commerce Automation Testing Project

This project demonstrates automated testing for an e-commerce web application using Selenium WebDriver with Java.

## Overview
The project focuses on validating core user workflows such as login, product browsing, and user interactions using a structured automation framework.

## Features
- Automated login functionality
- Product browsing and validation
- End-to-end user workflows
- Multiple test scenarios with assertions

## Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Maven

## Design Pattern
- Page Object Model (POM)

## Project Structure
- pages: Page classes and locators
- tests: Test cases and scenarios
- base: Setup and driver configuration (if available)
